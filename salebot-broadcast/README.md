# Рассылка клиентов через Salebot — без сервера

Локальный скрипт для ситуации: клиент прислал вам текст рассылки в Telegram, вы
хотите отправить его в его бот в Salebot, не заходя руками в интерфейс. Никакой
постоянно работающий бот или сервер тут не нужен — только Claude Code (или
терминал) на вашем компьютере, запускаемый по требованию.

## Как это работает

1. Клиент присылает вам текст рассылки в Telegram (как обычно).
2. Вы открываете в этой папке Claude Code (или сами открываете терминал) и
   говорите/пишете: «отправь эту рассылку клиенту `<Имя>`: `<текст>`».
3. Claude выполняет `send_broadcast.py` — скрипт показывает превью (кому, какая
   аудитория, какой текст) и спрашивает подтверждение `y/N` в терминале.
4. После вашего «y» скрипт отправляет запрос в Salebot Broadcast API
   (`POST https://chatter.salebot.pro/api/{api_key}/broadcast`), и печатает
   ответ Salebot.

Никакого фонового процесса, VPS или Docker не требуется — скрипт живёт ровно
столько, сколько выполняется команда.

**Важно:** этот API доступен только на тарифах Salebot Бизнес/Инфобиз. Точный
список поддерживаемых параметров см. в официальной документации:
https://docs.salebot.pro/rabota-s-api/api-konstruktora — если Salebot добавит
или переименует поля, их можно передать без правки кода через `--param key=value`.

## Настройка (один раз)

```bash
cd salebot-broadcast
cp clients.example.json clients.json
```

Заполните `clients.json` реальными данными по каждому клиенту:

```json
{
  "Стася": {
    "bot_id": "12345",
    "api_key": "xxxxxxxxxxxxxxxxxxxx",
    "default_group_id": null
  }
}
```

- `bot_id` и `api_key` берутся в Salebot: откройте проект клиента → настройки →
  раздел API.
- `default_group_id` — необязательно, ID списка/аудитории, если у клиента есть
  постоянная аудитория для рассылок (иначе указывайте `--group-id` при запуске
  или оставляйте пустым — уйдёт по умолчанию по настройкам Salebot).

`clients.json` содержит реальные ключи — он в `.gitignore` и никогда не
попадёт в репозиторий. Файл нужен только на вашем компьютере.

## Использование

```bash
# посмотреть, что уйдёт, ничего не отправляя
python3 send_broadcast.py --client "Стася" --message "Текст рассылки" --dry-run

# отправить (спросит подтверждение)
python3 send_broadcast.py --client "Стася" --message "Текст рассылки"

# указать конкретную аудиторию и время отправки
python3 send_broadcast.py --client "Стася" --message "Текст" \
  --group-id 98765 --send-time "2026-09-10 12:00:00"
```

Никаких внешних библиотек ставить не нужно — скрипт использует только
стандартную библиотеку Python 3.

## Типичный сценарий с Claude Code

Открываете Claude Code в этой папке (`salebot-broadcast/`) на своём компьютере
и просто пишете, например:

> Клиент Стася прислал: "Завтра открытие набора в группу, успей записаться!"
> Отправь это её аудитории.

Claude сам подберёт нужную команду `send_broadcast.py`, покажет вам превью и
дождётся вашего подтверждения перед реальной отправкой.
