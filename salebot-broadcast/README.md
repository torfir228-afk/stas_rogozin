# Рассылка клиентов через Salebot — без сервера

Инструмент для ситуации: клиент прислал вам текст рассылки в Telegram, вы
хотите отправить его в его бот в Salebot (в правильный, если ботов
несколько), не заходя руками в интерфейс — и не давая никому лишний доступ к
рабочим ботам.

Два способа запуска одной и той же логики:

- **`dispatcher_bot.py`** (основной сценарий) — маленький отдельный
  Telegram-бот. Вы форвардите ему сообщение клиента + пишете инструкцию,
  он показывает превью и ждёт вашего подтверждения кнопкой. Запускается
  вручную, когда нужно — постоянно работающий сервер не требуется.
- **`send_broadcast.py`** — та же отправка из командной строки/через Claude
  Code, без Telegram-интерфейса (пригодится для разовых ручных проверок).

## Важно про доступ

Ни я, ни `dispatcher_bot.py` не имеют доступа к вашим **рабочим** ботам
«Расцветай» — у диспетчер-бота свой отдельный токен, никак с ними не
связанный. Реальные API-ключи Salebot (которые дают право слать рассылки)
хранятся только в файле `clients.json` **на вашем компьютере** — этот файл
в `.gitignore`, в репозиторий не попадает и никогда не передаётся мне.

## Настройка (один раз)

### 1. Данные о ваших ботах Salebot

```bash
cd salebot-broadcast
cp clients.example.json clients.json
```

Заполните `clients.json` — для проекта «Расцветай» с двумя ботами нужна
**отдельная запись на каждого бота**, чтобы их нельзя было перепутать:

```json
{
  "Расцветай — Бот 1": {
    "alias": "1",
    "bot_id": "12345",
    "api_key": "xxxxxxxxxxxxxxxxxxxx",
    "telegram_username": "@rascvetai_bot1",
    "default_group_id": null
  },
  "Расцветай — Бот 2": {
    "alias": "2",
    "bot_id": "67890",
    "api_key": "xxxxxxxxxxxxxxxxxxxx",
    "telegram_username": "@rascvetai_bot2",
    "default_group_id": null
  }
}
```

- `alias` — короткое имя, которым вы будете указывать бота в инструкции
  диспетчер-боту (например, просто `1` или `2`).
- `bot_id` — Salebot: проект «Расцветай» → раздел **«Каналы»** — у каждого
  подключённого бота свой ID.
- `api_key` — обычно один на весь проект (настройки проекта → API), но
  проверьте на месте: если у ботов разные ключи, впишите каждому свой.
- `telegram_username` — необязательно, но настоятельно рекомендуется:
  показывается в превью перед отправкой, чтобы вы могли на глаз
  убедиться, что выбрали правильного бота.
- `default_group_id` — необязательно, ID списка/аудитории по умолчанию.

Посмотреть, что уже настроено:

```bash
python3 send_broadcast.py --list
```

### 2. Диспетчер-бот в Telegram

1. Создайте нового бота через [@BotFather](https://t.me/BotFather) —
   отдельного, специально для диспетчера (не рабочий бот клиента).
2. Узнайте свой личный Telegram ID (например, у [@userinfobot](https://t.me/userinfobot)).
3. Скопируйте `.env.example` в `.env` и заполните:
   ```
   DISPATCHER_BOT_TOKEN=токен_нового_бота
   OWNER_TELEGRAM_ID=ваш_telegram_id
   ```
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

Бот отвечает только вам (по `OWNER_TELEGRAM_ID`) — если кто-то другой найдёт
его и напишет, бот откажет.

## Использование диспетчер-бота

Запускаете, когда нужно разобрать рассылки:

```bash
python3 dispatcher_bot.py
```
(останавливается `Ctrl+C`, когда закончили — постоянно держать включённым не
обязательно).

В Telegram, в чате с этим ботом:

1. **Форвардите** сообщение клиента с текстом рассылки.
2. Следующим сообщением пишете инструкцию построчно:
   ```
   бот: 2
   время: 18:00
   кнопка: Записаться | https://example.com
   ```
   `время` и `кнопка` необязательны — без `время` уйдёт сразу.
3. Бот покажет превью (кому, когда, с какой кнопкой, весь текст) и кнопки
   **[✅ Отправить] [❌ Отмена]**.
4. Только по вашему тапу «Отправить» уходит запрос в Salebot.

**Про кнопки:** формат поля кнопки в Salebot Broadcast API не подтверждён
официальной документацией (не смог её открыть напрямую при разработке) —
при первом использовании кнопки проверьте результат на тестовой аудитории,
прежде чем слать на реальную.

## Использование `send_broadcast.py` напрямую (без Telegram-интерфейса)

```bash
# посмотреть, что уйдёт, ничего не отправляя
python3 send_broadcast.py --client "Расцветай — Бот 1" --message "Текст рассылки" --dry-run

# отправить (спросит подтверждение)
python3 send_broadcast.py --client "Расцветай — Бот 1" --message "Текст рассылки"

# указать конкретную аудиторию и время отправки
python3 send_broadcast.py --client "Расцветай — Бот 1" --message "Текст" \
  --group-id 98765 --send-time "2026-09-10 12:00:00"
```

Можно также попросить Claude Code сделать это за вас — откройте Claude Code
в этой папке и напишите, например:

> Клиент прислал: "Завтра открытие набора в группу, успей записаться!"
> Отправь это в Расцветай — Бот 1.

Claude подберёт команду, покажет превью и дождётся вашего подтверждения.

## Тариф Salebot

Broadcast API доступен только на тарифах **Бизнес/Инфобиз**. Точный список
поддерживаемых параметров — в официальной документации:
https://docs.salebot.pro/rabota-s-api/api-konstruktora — новые/переименованные
поля можно передавать без правки кода через `--param key=value` (в
`send_broadcast.py`).
